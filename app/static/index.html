Naming Templates

Blank resets to the default. A bad template (unknown token, bad format spec) silently falls back to the default for that file rather than failing the archive.

Tokens: {title}, {year}, {year_suffix} (" (2020)" or "" if unknown). The file always shares this name (extension appended automatically) -- see the "also rename file" option in Ready to Archive.

Tokens: {show_name}, {season}, {episode}, {code} ("S01E02"), {episode_title}, {episode_title_suffix} (" - Title" or "" if unknown), {absolute_episode} (cumulative episode count across seasons, e.g. "{show_name} - {absolute_episode:03d}" for anime-style naming -- falls back to the plain in-season episode number when it can't be computed), {part_suffix} (" - CD1"/"Part2"/etc for a multi-part rip, detected from the source filename, or "" for a single-file episode).
